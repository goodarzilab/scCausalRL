# exp20 load-bearing-A investigation — figures

Step-by-step visual story (generated by `evaluation/make_figures.py`; dataviz reference palette, validated).
Each panel: one axis, direct value labels, chance (0.5, red) and exp19-ceiling (0.647, green) reference lines.

**1 · Perturbation prediction** — `fig1_prediction_ladder.png`
Held-out zero-shot disc_resid across all exp20 arms (prior-off / objective-sweep / frozen). **No fix beats
the prior-off baseline (sparse_con 0.639 ≈ exp19 ceiling 0.647); whiten / resid / frozen collapse to chance.**

**2 · Causality (A load-bearing)** — `fig2_causality_Agap.png`
real-A vs zero-A vs shuffled-A drift-removed spearman (left) + A_gap across all arms (right).
**real ≈ zero ≈ shuffled; A_gap ≈ 0 everywhere — A does not improve prediction.**

**3 · Mechanism** — `fig3_mechanism.png`
probe_Dperm (shuffle decoder) ≈ 1.0 ≫ probe_A (remove A) ≤ 0.5; crossTF_div ≈ 0.02.
**The decoder carries prediction; A is a minor add-on; predictions are ~99% identical across TFs (mode collapse).**

**4 · Biology (GRN)** — `fig4_biology_grn.png`
CollecTRI AUROC prior-ON 0.98 → prior-off 0.57 (= co-expression floor = shuffled-A); fetal-atlas fate hierarchy 0.51 (chance).
**The projected GRN is prior memorization living in the decoder — no causal/developmental structure recovered.**

**5 · Objective sweep (R1–R6)** — `fig5_Rsweep.png`
Pseudobulk (R2/R4/R5/R6) lifts crossTF_div 0.03→0.2 and probe_A→0.9 (A engaged) — **but disc_resid stays at chance.**
Diverse-but-WRONG: the objective breaks mode collapse but not generalization.

**6 · Generalization is the wall** — `fig6_train_vs_heldout.png`
TRAIN-gene disc vs held-out disc. **sparse_con memorizes seen TFs (0.93) but drops to 0.62 held-out (+0.31 gap);**
shift magnitude stays full on unseen TFs (confidently wrong direction, not mean-regression).

**7 · Synthetic positive control** — `fig7_synthetic.png`
Planted A*/D*/generalizable descriptor→shift. **The shift-encoder generalizes (disc 0.66; perturbation-blind
localization → 0.90) but graph-recovery AUROC stays at chance (~0.5).** A is non-identifiable — the shift+decoder
are a sufficient statistic; forcing the gate sparse (L0 frontier) never recovers A.

## One-line verdict
Architecture is sound (generalizes on ideal data); **Joung is zero-shot-generalization-limited, and A is
non-identifiable/redundant in this shift-based class even on ideal data.** Levers: multi-context (Norman) for
generalization; a fundamentally different identification setup for load-bearing A.
